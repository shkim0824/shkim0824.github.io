# SeongHyeon Kim

Personal academic homepage: https://shkim0824.github.io/

A lightweight, responsive English homepage built with plain HTML and CSS. No build step or external dependencies.

## Edit

- `index.html`: profile, introduction, publications, and education.
- `styles.css`: typography, colors, and responsive layout.
- `.nojekyll`: serves these files directly on GitHub Pages.

## Preview locally

Run `python3 -m http.server 8000` in this directory, then open http://localhost:8000.

## Publish

GitHub Pages serves the root folder of the `main` branch. Push changes to `main` to update the website. Deployment progress appears in the repository's Actions tab.
